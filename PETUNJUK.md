# Komik Reader
1. Upload folder ini ke repo GitHub baru -> tab Actions -> Build APK -> unduh artifact APK.
2. Buka app -> Repo -> tempel URL file JSON repo (lihat contoh-repo.json).
3. Field "type": manhwa / manhua / manga. Selector format "css@atribut" (atribut: text, href, src).
4. Urutan bab diasumsikan terbaru di atas (bab berikutnya = indeks sebelumnya).
